# Sistema de combate Pokémon en Java

Proyecto de programación orientada a objetos realizado en Java.

## Funcionalidades
- Clases con herencia (Pokémon)
- Entrenadores con un Pokémon asignado
- Sistema de combate basado en niveles
- Relación entre clases (POO)

## Objetivo
Practicar herencia, asociación y uso de clases en Java.
